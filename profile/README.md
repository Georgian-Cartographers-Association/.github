## ჩვენ შესახებ / About

**საქართველოს კარტოგრაფთა ასოციაცია (სკა)** — პროფესიული გაერთიანება, რომელიც აერთიანებს საქართველოში კარტოგრაფიის, გეოდეზიისა და GIS სფეროს სპეციალისტებს.

**Georgian Cartographers Association (GCA)** is a professional body uniting cartographers, geodesists, and GIS specialists in Georgia. Officially recognized by the **International Cartographic Association (ICA)**.
